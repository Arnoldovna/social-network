# Traceability: BUGS → design decision

Every item of `docs/BUGS.md` (B-01 – B-142) with the decision that resolves it, where it lives, and how it is proven.
"Proven by" names the test layer (U unit, I integration, C component, E E2E/a11y, S static check: lint, stylelint,
utility checker, typecheck, gitleaks, review) and, for behavioural bugs, the test file that carries a `B-xx:`
regression test. Phase = BUILD-ORDER phase that implements it.
